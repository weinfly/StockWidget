# StockWidget

由GPT5协助开发，一个在 **Windows** 上运行的极简透明盯盘Widget浮窗，按指定股票代码实时显示行情表格，可选展示迷你 **K 线**（当天）。覆盖沪深京三市股票，并支持港股、美股、全球指数、国内外期货、即期外汇。支持拖拽、贴边隐藏、双模式显示、报警通知、右键菜单、设置面板、自动保存配置。

> 适合贴在屏幕一角随时查看 👀

> **出处与致谢**：本项目基于上游开源项目 **[sbr0574/StockWidget](https://github.com/sbr0574/StockWidget)**（[Apache License 2.0](http://www.apache.org/licenses/LICENSE-2.0)）二次开发，当前版本 **v1.6.0**。感谢原始作者 **sbr0574**。再分发相关约定见文末 [许可与出处声明](#-许可与出处声明)。

## ✨ 功能概览

**浮窗与窗口行为**

- **透明无框浮窗**：置顶显示，拖拽任意区域即可移动，**双击**浮窗可隐藏，右键展示快捷菜单。
- **贴边隐藏**：拖到屏幕四边自动收起，鼠标悬停露出边条时自动弹出。
- **双模式切换**：鼠标悬浮时显示“正常模式”，鼠标离开延迟后自动切换为“简易模式”，两种模式可分别配置显示的指标；也可关闭自动切换，手动固定使用某一模式。
- **全局快捷键**：默认 `Ctrl+Alt+F` 显示/隐藏浮窗、`Ctrl+Alt+C` 开/关鼠标穿透，均可在设置中自定义，并显示注册成功/失败状态。
- **鼠标穿透**：一键开关，开启后浮窗忽略所有鼠标事件、点击直达下层窗口（随时用快捷键关闭）。
- **窗口锚点**：指标列变化导致宽度增减时，可选择保持左对齐/右对齐。
- **系统托盘**：左键切换显示/隐藏；右键菜单含“显示/隐藏 浮窗 / 设置 / 退出”；Tooltip 展示总盈亏与各股指标明细。

**数据显示**

- **表格指标（可自由勾选）**：`代码 | 名称 | 现价 | 涨跌值 | 涨跌幅 | 盈亏 | 买一/卖一 | 委比 | 成交量 | 成交额 | 均价 | 日高 | 日低 | K线`
  - **买一/卖一**支持显示数量、价格或两者；代码可仅显数字、名称可限制显示字数（1–4 字/完整）
  - **现价触及当日最高/最低**时显示标记（标记符号 ↑/↓/涨停/跌停/涨/跌 均可自定义）
  - **涨跌停板时，均价自动切换为封单数量**
  - **K 线**为当日迷你 K 线，尺寸随字号同步缩放

- **刷新间隔**：可选 1/2/3/5/10/15/30/60 秒；浮窗隐藏时**暂停刷新**，显示后自动恢复。
- **表头点击排序**：显示表头后单击列头，按“**降序 → 升序 → 不排序**”循环；支持现价/涨跌/涨幅/盈亏/成交量/成交额/均价/委比等数值列（按真实数值而非显示串排序）；右键菜单“**快捷排序**”亦可。排序状态自动记忆，下次启动恢复。
- **持仓盈亏**：右键自选条目设置成本价/数量后显示“盈亏”列；托盘图标右下角叠加红/绿灯泡指示总盈亏。
- **分时图弹窗**：右键某只 **沪深京 A 股**→“查看分时”，弹出独立分时图窗口（价格线 + 均价线 + 昨收参考线 + 成交量柱，十字光标悬停查看），配色跟随浮窗主题，窗口内每 60 秒自动刷新（非 A 股品种不提供此菜单）。

**报警通知**（均通过系统托盘通知）

- **涨跌异动报警**：自定义多条规则（监控周期 1秒–10分钟 + 波动阈值 % + 冷却时间）。
- **新高/新低报警**：可分别开关，带冷却时间。
- **涨/跌停通知**：到达/离开涨跌停分别可开关，带冷却时间。
- **封单预警**：按股票设置多个阈值（正=涨停封单手数，负=跌停封单手数），封单跌破阈值或打开涨/跌停时通知。

**外观与其他**

- **颜色与不透明度**：涨/跌/表格/背景四色可设，支持恢复默认；表格、表头、背景、整体四档不透明度独立调节。
- **统一颜色 / 中性色**：可开启“统一颜色”让所有行情文字使用同一文字色（忽略涨跌分色）；关闭后可分别设置涨/跌/**中性**（非涨非跌）三色。
- **字体与行距**：字号 **6–15 pt**；行距为额外像素（行高 = 字高 + 行距）。
- **自选代码智能识别**：支持 A 股/美股/港股/全球指数/国内外期货/即期外汇，详见设置面板“使用说明”页。
- **程序图标**：可选默认/系统图标，或上传自定义 `.ico` 图标；**开机自动启动**可开关。
- **自动保存**：所有设置即时保存至与 exe 同目录下的配置文件（`SW_config.json`）。

## 🧰 运行环境

右侧Releases已有打包好的程序，**可直接下载使用**

若要通过代码脚本形式运行，则需要：

- Windows 10/11
- Python **3.13+**（发布构建使用 3.13，其他 3.x 通常也可）
- 依赖见 `requirements.txt`（`PySide6`、`requests`、`keyboard`，打包用 `pyinstaller`）

```powershell
pip install -r requirements.txt
```

> 本项目也支持 [uv](https://docs.astral.sh/uv/)：`uv sync --group build`

## ▶️ 运行 & 打包

### 运行

```powershell
python .\main.py
```

使用 uv 时：

```powershell
uv run python main.py
```

### 打包成.exe

使用仓库内的 spec 配置（推荐）：

```powershell
pyinstaller .\StockWidget.spec --noconfirm
```

输出位于 `dist/StockWidget.exe`。

> 打包配置见 `StockWidget.spec`（入口 `main.py`，`resources/` 目录整体打入，图标为 `resources/icons/StockWidget.ico`）。
> 若不使用 spec，等效的命令行方式为：
>
> ```powershell
> pyinstaller -F -w .\main.py --name StockWidget --icon .\resources\icons\StockWidget.ico --add-data ".\resources;resources"
> ```

> 提示 `No module named 'PIL'`：请先 `pip install Pillow`。
> 任务栏/任务管理器图标不生效：
>
> - 运行时图标由 `stockwidget/app.py` 中的 `setWindowIcon()` 提供，从 `resources/icons/StockWidget.ico` 加载；
> - EXE 图标由 spec 中的 `icon=` 提供；
> - 某些情况下需要**重启资源管理器**（任务管理器 → Windows 资源管理器 → 重新启动）。

## ⚙️ 设置面板

设置面板分为 7 个页签：

- **自选列表**：代码增/删/改/上移/下移；选中条目可通过按钮或**右键菜单**设置**持仓成本**与**封单预警**。代码自动规格化并去重，支持智能识别（详见面板内“使用说明”页）：
  - A 股/美股：纯数字或字母（`600519`、`AAPL`）
  - 港股：5 位数字（`00700`）
  - 全球指数：大写简称（`DJI` 道指、`NKY` 日经）
  - 国内期货：品种+数字（`RB0` 螺纹钢）；外盘期货：国际代号（`XAU`、`CL`）
  - 外汇：6 位货币对（`USDJPY`）
  - 冷门品种可直接键入新浪完整前缀代码（如 `b_XU100`）强制放行

- **显示数据**：刷新间隔；双模式切换开关与延迟；正常/简易两套指标分开勾选；买一/卖一显示方式（数量/价格/两者）；代码仅显数字、名称显示字数；标记符号（日高/日低/涨停/跌停/涨/跌）自定义。
- **外观**：表格外观（显示表头/显示网格）；涨/跌/表格/背景四色与恢复默认；表格/表头/背景/整体四档不透明度；字体、字号（6–15 pt）、行距。
- **常规**：全局快捷键自定义（显隐键 + 鼠标穿透键）与注册状态显示；鼠标穿透开关；开机启动；窗口锚点（左/右对齐）；程序图标（默认/系统图标/自定义 `.ico`）。
- **报警**：涨跌异动报警（多规则：周期+阈值%+冷却）；新高/新低报警；涨/跌停通知（到达/离开分别开关）；均带冷却时间防刷屏。
- **使用说明**：代码智能输入指南。
- **关于**：显示版本号、原始作者、官方仓库地址、许可协议（Apache License 2.0）及再分发声明（需保留 LICENSE/NOTICE 并注明原作者与仓库）；含“**检查更新**”按钮，后台比对 GitHub 最新 Release。

> 修改**实时生效**，即时保存至 `SW_config.json`。

## 🖱️ 操作速览

- **拖动窗口**：按住窗口任意位置拖动（拖动中暂停刷新，松手恢复）。
- **双击浮窗**：隐藏。
- **贴边隐藏**：拖到屏幕边缘自动收起，悬停露出的边条自动弹出。
- **右键浮窗**：在网页打开（腾讯/新浪，须右键具体股票行）/ 查看分时（仅沪深京 A 股）/ 快捷排序 / 显示指标 / 显示表头 / 显示网格 / 鼠标穿透 / 双模式切换 / 正常·简易模式 / 设置… / 隐藏浮窗。
- **表头排序**：显示表头后单击列头按降序→升序→不排序循环。
- **全局快捷键**：`Ctrl+Alt+F` 显示/隐藏浮窗、`Ctrl+Alt+C` 切换鼠标穿透（均可自定义）。
- **系统托盘**：
  - 左键：显示/隐藏浮窗
  - 右键：显示/隐藏 浮窗 / 设置… / 退出
  - Tooltip：总盈亏 + 各股指标明细；图标右下角红/绿灯泡指示总盈亏

- **在网页打开**：右键某只股票 → “在网页打开”可选**腾讯股票**或**新浪股票**在新窗口查看该股行情页。
- **打开雪球页面**：Ctrl + 单击股票行（第一列）。
- **设置成本/预警**：设置面板自选列表中，选中条目后点击“设置成本”/“封单预警”按钮，或右键条目快捷菜单。

## 🌐 数据来源 & 网络

- 行情通过 `requests` 从 **新浪财经**接口（`hq.sinajs.cn`）获取，覆盖 A 股、港股、美股、基金、全球指数、期货与外汇。
- 程序仅发起 GET 请求，不包含任何账户/交易操作；数据存在一定延迟，仅供参考。请根据自身网络环境决定是否使用代理或更换数据源。
- 浮窗隐藏时会暂停刷新，显示后自动恢复，减少不必要的请求。
